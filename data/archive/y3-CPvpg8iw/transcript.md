# MY FAVORITE TRICEP EXERCISE

seems like a lot of people are still confused on setting up one of my favorite tricep movements the cross cable extension does a great job of working all three heads of the tricep and it's very joint friendly when set up properly it's a bit easier to see and set up single arms so here's an example notice how i'm lining myself up for this movement i've positioned myself so that the cable is now lined up through my shoulder my elbow and my wrist my upper arm is in slight extension meaning i'm keeping it slightly pulled back and i'm keeping it fixed in place from there all you have to do is focus on extending and you've got a great exercise

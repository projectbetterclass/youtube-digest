# I feel like the term sleeper build is getting thrown around a lot

<https://www.youtube.com/shorts/5ycAubxBWo0>

I think that we need to change the way that sleeper build is being used online because it's very often just lean individuals wearing big clothes and then they have a sleeper build underneath. Like we can see that you have a good physique. If you were bulked up in the same shirt, it would be even more obvious. I like sleeper build for people who don't look like they should be able to lift as much as they can lift. Like if you're 120 lb and you're putting up 405 on bench, sleeper build.

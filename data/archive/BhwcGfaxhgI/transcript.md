# Love a good clavicular cable press!

<https://www.youtube.com/shorts/BhwcGfaxhgI>

If you're not lucky enough to have a sick incline press like this, then you do have some alternatives that you're able to do at most commercial gyms. If you can set this one up seated, then that's even better as you'll have better bracing and stability. All you have to do is line up the cables with the upper chest fibers, which run from the midline of the clavicles towards the upper arm. Notice how I'm keeping the cables in line with my forearms as well. And here is the single arm version of that when I want to load up a bit heavier, but don't want to set up the seated version. This way I can brace with the non-working arm and have a bit more stability. Try it out next chest day.

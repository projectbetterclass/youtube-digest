# Katana extension set-up

<https://www.youtube.com/shorts/xYFS0w_rLIc>

If you want big triceps, katana extensions are one of my favorite tricep overhead extension exercises, especially for people who may have trouble with elbow issues when using a bar or a short rope when doing their overhead extensions. Doing them unilaterally like this or on a dual cable machine can help with aligning the movement and making it feel a bit easier on your elbows. Pay attention to the setup here. Make sure that you don't have the cable set too low as having it set lower than necessary is going to one make it harder to get into position and then also make it more likely that the cable is going to sway as you're doing the exercise making it a bit less stable. If you were doing this exercise unilaterally then an easy way to set up is having the cable running down the middle of your spine as shown here. If you're doing the exercise bilaterally, here is an easy way to get in position. And as you may notice, the cable is no longer going to be running vertically down the middle of your back, but it's going to be coming in at an angle. And you just want to make sure that the cables are lined up with the upper arm in the direction that you were extending to. While I don't particularly like using a cuff for this exercise, as I find that it's a bit more prone to sliding up and down the arm as you're doing the exercise, I also wouldn't just grab the cable like this. I would suggest using a D handle. That way it can rotate around the canvas strap as you're doing the exercise and you have a better grip. Take into account if you're doing a push down on the same day that they are both training elbow extension. So I would split the volume accordingly. So, if you're doing three or four total sets, you could do two sets of the push down, one set of the katana extension, or the other way around. That is currently what I've been doing twice a week to help with growing my triceps, and it's been working out great for myself and my training teams. Hope this helps.

# The problem with face-pulls

<https://www.youtube.com/shorts/GhEFWcfkWp4>

baseballs are a fine exercise for targeting the upper back tissues but it has two big problems number one it doesn't have any external support to brace against and number two it has a fairly poor resistance profile the way we can remedy this is by choosing exercises that are either externally supported like chest supported rows or reverse flies in a machine or simply choosing exercises that have better resistance profiles meaning exercises that are better matched to our strength levels so chest supported rows and reverse flies are likely a little bit more effective from a hypertrophy standpoint than face poles for these reasons

# Want thicker arms?

<https://www.youtube.com/shorts/fxyz7CTYV8s>

If you have an issue with your arms looking real thin from the front, try out this exercise. This is an exercise that I just added to my exercise library for the new meso cycle that is starting this week. This is a preacher pad hammer curl. I like to sit on the opposite side from the arm that I'm working as I find that it makes it a bit easier to line things up. And pay attention here, notice how I'm coming all the way down. I'm not stopping shy of that. I'm allowing for full elbow extension because the elbow is something that can be fully extended and you should not be scared about loading that position. Everyone is scared about popping their bicep, but so long as you're controlling it into that end range and you're using an appropriate amount of weight, it's fine. That preacher pad hammer curl is a great choice for biasing the brachialis, that deep elbow flexor muscle that sits under the bicep. So, if you have an issue with small looking arms, it's a good idea to include an exercise that biases that. For a complete elbow flexor workout, you can split up the volume between that exercise and your favorite supinated curl like a regular standing dumbbell alternating curl where the palm is facing up. This is going to do a good job of biasing the biceps. So, if you're doing four or five total sets for the elbow flexors, then you would just split up that volume between those two different exercises.

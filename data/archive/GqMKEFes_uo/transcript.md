# Stop doing curls???

<https://www.youtube.com/shorts/GqMKEFes_uo>

there's absolutely nothing wrong with locking your elbow in the bottom of a preacher curl and the people that get hurt doing this are simply just moving past their ability to tolerate the load in addition doing a curl like this is very different from having the bench angled lower where there's a lot more load toward the bottom so in this variation the elbow is a lot more loaded when it's straight and in this variation the elbow is a lot more loaded halfway up so if you're sensitive to this fully locked position start at a higher angle and then progressively move the bench sound so that you can load that angle a little bit more in any case build resilience to the position don't avoid it

And for my favorite Smith machine chest supported row setup, we have this little number right here. It's incredibly easy to set up. You're going to set a bench upright within the Smith machine, throw a yoga mat over the top for some cushion, and then lean over it. The way that I'm performing it is going to be more lat biased due to the narrow arm path, but it's very easy to make it upper back biased. If you wanted to make this more upper back biased involving more of the traps and rhomboids, then you would simply use a wider grip, which is going to result in a wider arm path, therefore involving the lats less. This is one of my favorite options if you don't have a chest supported row at your gym due to the easy setup. You can also perform Kelso shrugs on this machine using the exact same setup.

This looks like a great way to load wrist flexion. And you can even do wrist extension by putting your forearm on top of the quad, setting the cable low, and then extending from there. It's a much better way to set up cable reclection than doing it standing like this with no external bracing, which I see a lot of people doing. However, if your gym has one of these bars on the cable machine, then you can set it up like this standing. This bar here is essentially doing the same thing that his leg was doing by providing that external bracing and making it much better for isolating the forearm muscles. And while we're on the topic of forearm training, this is an excellent way to set up wrist extension on the cable machine, whether you have that bar or not. This is a variation that I saw from Eugene Teao and I quite like it because it loads that lengthen and position for the wrist extensors unlike a regular dumbbell wrist extension done on a bench which is going to load more of that mid to short range. Take one wrist flexion, one wrist extension exercise from this video. Do them twice a week, two sets each.

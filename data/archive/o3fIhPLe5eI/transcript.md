# What Does Ontology Mean?

the ontology is a set of Concepts and categories in a subject area or domain that shows their properties and the relations between them for example you might hear Alex karp say something like the ontology allows analytics teams data scientists and business decision makers to collaborate in real time ontology is a word used by paler a lot it's a keystone across their product offering but a word not often used in day-to-day life so what really is it data is stored in objects and links otherwise known as the ontology objects represent real world Concepts like an airplane vehicle or customer while links represent the relationships between objects so to put it simply the ontology is the relationship between a set of variables the object layer takes the data stored in tabular data sets rows and Columns of data like a spreadsheet and converts it into a series of Concepts that anyone in the organization can understand in addition to helping make data more understandable converting data from data sets into objects and links unlocks a broad set of tools and Foundry for interacting with objects you can Define actions that describe how objects can be changed by people in your organization this enables you to build applications that access data from objects and capture user decisions back into the system the definitions of objects links and actions together make up what is called the ontology a digital representation of your organization develop veling and using the ontology to translate data into operational outcomes is a key part of getting value out of Foundry

# Forearm exercise that trains the wrist extensors in the lengthened position

<https://www.youtube.com/shorts/JplL-GqDOdc>

If you have small little baby forearms that everybody points and laughs at whenever you walk into a room, then try out this exercise. I think the first person that I saw doing these was Eugene Teo, and after trying it, I immediately added it to my exercise library because it's a nice way to train the wrist extensors in a more lengthened position compared to say a dumbbell wrist extension. When setting this up, you don't have to set the cable super high. Just have it set up right above where the cable would be racked. This is going to train these muscles right here in the lengthened position. Unlike a dumbbell wrist extension, you don't have to think about bringing the wrist up towards the elbow. All you're going to do is allow for a full wrist bend and then come back to a neutral position. If you truly want meaty forearms and you want a more complete forearm workout, then you can pair this with something like a dumbbell [music] wrist flexion exercise where the forearms are supported on the bench. And something like a dumbbell wrist extension exercise as this exercise is going to be harder in the shortened position for those wrist extensor muscles. If I were to do all of these in a single workout, then I would probably order it dumbbell wrist flexion, dumbbell [music] wrist extension, and then cable wrist extension as that's going to be finishing that muscle in the lengthened position. >> [music]

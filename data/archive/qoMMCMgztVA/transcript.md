What's the tech stack behind this nearly million-dollar SaaS in 2026? >> So, we use Convex for our back end and database. We use Vercel for hosting the front end. We use Railway to host our microservice that actually builds the content. We use Clerk for very simple authentication. We use Resend for all our transactional and mailing list emails. We use Axiom for logs and observability. We use OpenAI and Claude models just to generate the copy and generate the captions. We use File AI for all our image and video generation. We use Claude code on the 20X Max plan, which is an absolute must for the speed that we ship at.

So, let's say you finally decide to set up the eval system. Let's go over some of the common mistakes that I made when setting up the system that you should avoid. The first mistake that you have to watch out for is not correctly setting up your judges. Because if the judges are wrong, then the scores literally don't even matter at that point. The eval can't be trusted and is not effective. You have to be very careful with the judges because, remember, some of them are LLMs, too. Hard-coded ones are usually fine, like if you're just checking, "Does it respond with the right format?" or "Are all of the fields being returned?" That's pretty black and white, super easy. But, when you're using an LLM as the judge, it can hallucinate, too. Here's an example of where that happened to me. In my case, the AI was responding with pretty reasonable-looking calorie estimates. It even cited sources. Like, it said, "I found the nutrition data from Bob's Burgers and Brew." The judge saw that, took it at face value, and said, "Cool, everything checks out here. These look like good sources." and it gave it a really good score. But, then when I manually went and verified it, I noticed that the sources didn't actually exist. It hallucinated the sources. But, the judge that I made was not built to double-check that. It was just built to check if the response looked good, not if it was honest. So, I had to go back, tweak the judge so that it actually double-checks the sources before giving the score. So, double-check all your judges, especially if you're just getting started with this stuff. The second biggest mistake that I've made that I've been seeing a lot of people make is having very bad test cases.

# Explaining deadlifts but we both have CTE

<https://www.youtube.com/shorts/H9GmZKjLaB8>

If deadlift with straight knee, more hamstring. If deadlift with bent knee, more glute. If deadlift with more round back, more spine load. Make back stronger. If deadlift with straight back, equals more hips. No variation equals bad. All variations good. Pick variation that is best for goal.

# Here’s how I like to use this set up!

[music] >> This is in fact a sick way to set up a glute kickback, especially for people who tend to feel the non-working leg more than the working leg. I really like doing and programming these, but with one minor change. Instead of having the cable set so high up to load the lengthened position for the glutes, I prefer setting this up that way you're mainly training the mid to short range. That lengthened position is already getting trained really well with your squat movements and hinges. This is an example of the setup for a gluteus kickback, but it would be basically the same thing, except you'd be kicking straight back instead of back and out. Since most people are already doing some kind of leg press, squat, RDL for their glutes, that's training the glutes in that more lengthened position. I think this exercise is better served for training that short position. And it's going to be much more effective and easier for you to load that lengthened position with something like a single-leg leg press compared to something like this, which isn't going to have quite so good bracing for that range of motion. Hope this helps, and as always, make sure to like and follow for more efficient training tips.

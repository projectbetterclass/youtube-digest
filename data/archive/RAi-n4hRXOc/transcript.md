# Even if all you have is a cable machine I think there are still better ways to load the back

<https://www.youtube.com/shorts/RAi-n4hRXOc>

I love variations of these exercises, but I do not love these exercises. There is no reason to be doing pull-downs or rows on the ground when you have access to a seated pull-down and a seated cable row or ideally a chest supported row. Things like this will work for a little bit as a beginner, but once you get stronger, which will happen relatively quickly as a newer lifter, you're not going to be able to load what you should be able to load due to the poor bracing of these exercises. Let's quickly go over some better alternatives to these exercises. [music] Instead of this, I would suggest doing a wide grip lat pull-down, which is going to give you a much better lat stimulus. You'll have a much better grip using a bar, especially if you're using straps, and then you'll be locked in with the thigh pads, so you'll have much better bracing. I would actually disagree that this is going to be trap biased as the lats and the rear delts still have really good leverage in this pull-down. If you wanted to do a better job of biasing the traps, I would do this on a chest supported row like a T-bar row. If your gym doesn't have this, then you can do this chest supported with dumbbells. The important thing though is going to be the arm path. Use a more flared arm path with the elbows falling slightly under the shoulders when you're pulling back. If your goal is traps, then you can stop once the arms are around in line with your torso and you reach full scapula retraction. And if you wanted to get more rear delts out of this, then you can pull back as far as possible, getting the arms as far back behind the body as you can. I'm personally not a big fan of this face pull setup since the hand is so close to the shoulder joint, you're not loading the rear delts nearly as well as you could be, and there's a lot of unnecessary loading on the elbow flexors like the brachialis and brachioradialis. You can instead stick with a reverse pec deck or a cable rear delt fly using a similar arm path. Try this out so you don't have to sit on the dirty gym floor, and as always, make sure to like and follow for more efficient training tips.
